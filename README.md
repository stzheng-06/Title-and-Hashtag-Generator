# AI 标题和标签生成器

一个基于 AI 的智能标题和标签生成工具，专为内容创作者和营销人员设计。支持多语言输出、自定义配置和灵活的生成规则。

## ✨ 功能特色

- 🤖 **AI 驱动生成** - 基于先进的 AI 技术生成高质量标题和标签
- 🌍 **多语言支持** - 支持中文、英文、西班牙文等多种语言输出
- ⚙️ **灵活配置** - 支持多种配置方案，自定义背景信息和生成规则
- 📋 **批量处理** - 支持多关键词输入和批量生成
- 💾 **本地存储** - 配置数据本地持久化，保护隐私
- 📱 **响应式设计** - 完美适配桌面和移动设备

## 🚀 快速开始

### 环境要求

- Node.js 18+ 
- npm 或 yarn

### 安装步骤

1. 克隆项目
\`\`\`bash
git clone <repository-url>
cd title-and-hashtag-generator
\`\`\`

2. 安装依赖
\`\`\`bash
npm install
\`\`\`

3. 启动开发服务器
\`\`\`bash
npm run dev
\`\`\`

4. 打开浏览器访问 [http://localhost:3000](http://localhost:3000)

## 📖 使用指南

### 1. 配置管理

首次使用需要创建配置：

1. 点击右上角的"配置管理"按钮
2. 创建新配置或使用快速创建
3. 填写以下信息：
   - **配置名称**: 为配置起一个有意义的名字
   - **背景信息**: 描述你的身份和内容创作需求
   - **输出语言**: 选择生成内容的语言
   - **基础标签**: 添加与你内容相关的基础主题标签
   - **生成规则**: 选择适合的生成规则
   - **API Key**: 输入你的 aihubmix API Key

### 2. 生成标题和标签

1. 确保已选择一个配置
2. 在关键词输入框中输入相关关键词（用逗号分隔）
3. 点击"生成标题和标签"按钮
4. 等待 AI 生成结果

### 3. 管理结果

生成完成后，你可以：
- 查看生成的标题和标签
- 单独复制某个标题或标签
- 批量复制所有标题或标签
- 下载结果为文本文件
- 重新生成内容

## 🔧 API 配置

本应用需要 aihubmix API Key 才能正常工作：

1. 访问 [aihubmix](https://aihubmix.com) 注册账号
2. 获取 API Key
3. 在配置中填入 API Key
4. 选择合适的AI模型（推荐使用 Gemini 2.0 Flash Lite）

### 支持的AI模型

- **Gemini 2.0 Flash Lite** (推荐) - 轻量快速，成本低
- **Gemini 2.0 Flash** - 平衡性能与速度
- **Gemini 2.5 Flash Lite** - 最新版本轻量模型
- **GPT-3.5 Turbo** - 快速、经济的选择
- **GPT-4** - 更强大的理解和创作能力
- **GPT-4 Turbo** - 速度和性能的平衡
- **Claude-3 Sonnet** - 高质量的文本生成
- **Claude-3 Haiku** - 快速响应

**注意**: API Key 仅在本地存储，不会上传到服务器。

## 🎯 生成规则说明

应用支持以下生成规则：

- **不使用表情符号**: 生成纯文本内容
- **不使用换行符**: 确保内容在一行内
- **标签全部小写**: 标准化标签格式
- **标题长度限制**: 控制标题长度
- **标签数量限制**: 限制生成的标签数量
- **避免重复标签**: 确保标签唯一性
- **相关性要求**: 只生成高度相关的内容

## 🔍 使用技巧

1. **关键词选择**: 选择 3-10 个相关性强的关键词效果最佳
2. **背景信息**: 详细描述你的行业和内容类型有助于生成更精准的结果
3. **配置管理**: 为不同类型的内容创建不同的配置方案
4. **结果优化**: 根据生成结果调整关键词和配置规则
